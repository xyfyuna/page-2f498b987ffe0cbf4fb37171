品牌简介

mbSurf 定位为清晰易用的机场服务：用订阅链接对接主流客户端，节点覆盖常用地区，线路区分日常浏览、流媒体解锁与游戏加速。我们把配置流程写清楚，减少从开通到连上的试错成本。官方网站是获取套餐信息、订阅说明与客户端下载指引的唯一推荐入口，请勿通过不明来源安装软件或填写订阅。

服务能力按套餐分层：基础版满足轻量日常访问，旗舰版强化原生流媒体与 IPLC 游戏线路，团队版面向多设备与定制路由。流量按月重置，设备数按同时在线计算。节点会随线路质量调整，不在此页虚构测速分数或用户评分。

在公共 Wi-Fi 或不稳定运营商网络下，用加密隧道保护账号与资料传输；差旅时切换就近节点即可继续使用同一订阅。

操作说明与配置流程

按纵向步骤完成即可：先确定套餐，再下载客户端，导入订阅后选节点连接。下列步骤同时适用于 Windows、macOS、Android 与 iOS 上的主流机场客户端。

第一步：选择套餐并完成订阅

对照流量、设备数与线路类型选择基础版、旗舰版或团队版。需要 Netflix 等完整解锁或游戏专线时优先旗舰版；多人共用选团队版。完成支付后打开账户页，复制机场订阅链接并妥善保存，不要公开传播。

第二步：下载官方客户端

个人电脑常用 Clash Verge、Clash Meta、v2rayN；macOS 可用 ClashX Meta 或 Stash；Android 可用 Clash Meta for Android；iOS 常用 Shadowrocket、Stash、Quantumult X。请只通过本站「官方下载」指引获取安装包或商店名称，避免来路不明的破解包。

第三步：导入机场订阅

打开客户端的订阅或 Profiles 页面，选择「从 URL 添加」，粘贴 mbSurf 订阅链接并更新。成功后会出现节点分组。若更新失败，检查链接是否完整、系统时间是否准确，再尝试更换网络后重新拉取。

第四步：选择节点并连接

日常浏览选香港、日本、新加坡等常规节点；流媒体选带解锁标识的线路；游戏选 IPLC 或优化分组。开启系统代理或 TUN / 增强模式，确保终端与浏览器走同一通道。连接成功后再打开目标应用。

第五步：分流、更新与排障

按需开启规则分流（国内直连、国外代理）。建议每周更新一次订阅以同步节点。无法访问时依次尝试：更换节点、关闭冲突 VPN、重装配置、检查流量是否用尽。旗舰版与团队版可通过优先工单联系支持。

常见问题

mbSurf 是机场还是 VPN？如何搭配客户端使用？

mbSurf 以机场订阅方式提供代理节点，在 Clash、Shadowrocket 等客户端中导入即可当 VPN 梯子与网络加速器使用。官网负责套餐、订阅说明与下载指引，具体连接由你选择的客户端完成。

如何从官网完成客户端下载并导入订阅？

先在套餐页开通，复制订阅链接；再根据系统选择对应客户端（见「官方下载」一节）；在客户端中用 URL 添加订阅并更新节点，最后选线路连接。五步配置流程与此一致。

基础版、旗舰版、团队版应如何选择？

轻度浏览与少量视频选基础版（100GB / 3 设备）。需要完整流媒体解锁、游戏 IPLC 与优先支持选旗舰版。多人、多设备或需要定制路由选团队版。年付价格已在各套餐中标明。

流量、设备数和同时在线如何计算？

流量按自然月周期统计上行与下行总和，用尽后需等待重置或升级。设备数限制的是同时在线会话，不是历史绑定台数。超出时旧连接可能被踢下线，团队版额度更高。

是否支持 Netflix 等流媒体以及游戏加速？

基础版提供基础流媒体解锁，旗舰版强调全节点原生解锁。游戏方面旗舰版含 IPLC 专线优化。若某部影片或区服仍限制，可更换解锁分组节点，或查看工单公告中的线路说明。

连接失败或订阅更新不了怎么办？

核对订阅链接完整、设备系统时间正确、客户端版本不过旧。尝试更换网络后重新更新，关闭其他 VPN 后再连。仍失败时，旗舰版与团队版可走优先工单，基础版按普通队列处理。
